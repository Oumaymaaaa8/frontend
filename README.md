# Projet de Gestion de Locations Immobilières

Ce projet est une application web dédiée à la gestion des locations immobilières pour une agence, utilisant Vue.js pour le frontend, Laravel pour le backend et MariaDB comme base de données.

## Table des matières

- [Introduction](#introduction)
- [Technologies](#technologies)
- [Installation](#installation)
- [Contribuer](#contribuer)

## Introduction

Ce projet vise à fournir une solution complète pour la gestion des locations immobilières pour les agences. L'application permet aux utilisateurs de gérer les propriétés, les locataires, les contrats de location et les paiements de manière efficace.

## Technologies

Le projet utilise les technologies suivantes :

- **Frontend** : Vue.js
- **Backend** : Laravel
- **Base de données** : MariaDB
- **Environnement de développement** : Node.js et Composer

## Installation

Pour installer et exécuter ce projet, suivez les étapes ci-dessous :

1. Clonez le dépôt.
2. Installez les dépendances pour le backend et le frontend.
3. Configurez les variables d'environnement.
4. Exécutez les migrations pour la base de données.
5. Démarrez les serveurs de développement pour le backend et le frontend.
